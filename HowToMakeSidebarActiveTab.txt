Ab hum ekdum starting se end tak flow dekhenge — click → function → state → JSX condition → class → CSS → screen par submenu open/close.

Aapke case ko maan lete hain:

Dashboard = 0
Product   = 1
Category  = 2
Orders    = 3

Aur code:

const [activeTab, setActiveTab] = useState(0);

const isOpenSubmenu = (index) => {
  setActiveTab(activeTab === index ? null : index);
};

1. Sabse pehle State
const [activeTab, setActiveTab] = useState(0);

Iska matlab:

activeTab = 0

Initially 0 hai.

Humne decide kiya:

0 = Dashboard
1 = Product
2 = Category
3 = Orders

To initial state:

activeTab = 0

iska matlab:

Dashboard active/open hai.

2. Ab Product ka Button
Aapka Product button:

<Button
  onClick={() => isOpenSubmenu(1)}
>
  Product
</Button>

Yahan sabse important cheez:

isOpenSubmenu(1)

1 Product ka index hai.

Jab user Product par click karega, React ye function call karega:

isOpenSubmenu(1)

3. Click ke baad Function chalega
Function:

const isOpenSubmenu = (index) => {
  setActiveTab(activeTab === index ? null : index);
};

Ab function ke andar:

index = 1

kyunki Product se 1 bheja tha.

Aur current state:

activeTab = 0

To ye condition check hogi:

activeTab === index

Actual values:

0 === 1

Result:

false

To ternary ka : wala part chalega:

index

Matlab:

setActiveTab(1);

4. State change hui
Pehle:

activeTab = 0

Ab:

activeTab = 1

React ko pata chala ki state change ho gayi.

React component ko re-render karta hai.

Yahan se next important step hai.

5. React JSX ko dobara check karega
Aapke Product submenu me:

<div
  className={`submenuWrapper ${
    activeTab === 1 ? 'colapse' : 'colapsed'
  }`}
>

Ab current:

activeTab = 1

Condition:

activeTab === 1

Actual:

1 === 1

Result:

true

Isliye:

colapse

class lag jayegi.

Final HTML roughly:

<div class="submenuWrapper colapse">

6. Ab CSS ka role aata hai
Aapne CSS likhi hai:

.submenuWrapper.colapse {
  height: auto;
}

.submenuWrapper.colapse .submenu {
  opacity: 1;
}

To browser dekhta hai:

<div class="submenuWrapper colapse">

Aur CSS bolti hai:

height: auto
opacity: 1

Isliye submenu visible/open ho jata hai. 🎉

Pura flow ek saath
User Product par click karta hai
            ↓
onClick={() => isOpenSubmenu(1)}
            ↓
isOpenSubmenu(1)
            ↓
index = 1
            ↓
activeTab === index ?
            ↓
0 === 1
            ↓
false
            ↓
setActiveTab(1)
            ↓
activeTab = 1
            ↓
React re-render
            ↓
activeTab === 1 ?
            ↓
true
            ↓
className = "submenuWrapper colapse"
            ↓
CSS .colapse apply
            ↓
height: auto
opacity: 1
            ↓
Product submenu OPEN

Ye complete journey hai.

7. Ab Product ko dobara click karte hain
Abhi:

activeTab = 1

Product par dobara click:

onClick={() => isOpenSubmenu(1)}

Function:

isOpenSubmenu(1)

Ab:

index = 1
activeTab = 1

Condition:

activeTab === index

Actual:

1 === 1

Result:

true

To ternary:

true ? null : index

Result:

null

Isliye:

setActiveTab(null);

8. State ab null
Pehle:

activeTab = 1

Ab:

activeTab = null

React re-render karega.

Product ka JSX:

activeTab === 1 ? 'colapse' : 'colapsed'

Actual:

null === 1

False.

To:

colapsed

class lagegi.

Final:

<div class="submenuWrapper colapsed">

CSS:

.submenuWrapper.colapsed {
  height: 0px;
}

.submenuWrapper.colapsed .submenu {
  opacity: 0;
}

Browser:

height = 0
opacity = 0

Product submenu close. ✅

9. Ab Category click karte hain
Category:

<Button onClick={() => isOpenSubmenu(2)}>
  Category
</Button>

Click:

isOpenSubmenu(2)

Current:

activeTab = null
index = 2

Condition:

null === 2

False.

To:

setActiveTab(2);

Ab:

activeTab = 2

10. Category ka JSX
Category ka submenu:

<div className={`submenuWrapper ${
  activeTab === 2 ? 'colapse' : 'colapsed'
}`}>

Current:

activeTab = 2

So:

2 === 2

True.

Class:

colapse

  height: auto;
}

.colapse .submenu {
  opacity: 1;
}

Result:

Category OPEN

11. Sabse important: Product automatically close kaise hua?
Ye magic nahi hai. 😄

Product ke liye condition:

activeTab === 1

Category click ke baad:

activeTab = 2

To:

2 === 1

False.

Isliye Product ko:

colapsed

class milegi.

Aur CSS:

.colapsed {
  height: 0;
}

Product close.

Category ke liye:

2 === 2

True.

To:

colapse

Category open.

Isliye ek hi state sabko control kar rahi hai.

12. Isliye isToggleSubmenu ki zarurat nahi
Aap pehle ye kar rahe the:

const [activeTab, setActiveTab] = useState(0);
const [isToggleSubmenu, setIsToggleSubmenu] = useState(false);

Do states thi:

activeTab
    ↓
kaunsa menu?

isToggleSubmenu
    ↓
open ya close?

Isme dono states ko synchronize karna padta tha.

Ab humne sirf ek state rakhi:

const [activeTab, setActiveTab] = useState(0);

Aur iska meaning hai:

activeTab jis menu ka index hai, wahi menu open hai.

Example:

activeTab = 0 → Dashboard open
activeTab = 1 → Product open
activeTab = 2 → Category open
activeTab = 3 → Orders open
activeTab = null → sab close

Ye much cleaner hai.

Ek cheez aur: setActiveTab kya karta hai?
Ye bhi samajhna important hai.

setActiveTab(2);

Iska matlab activeTab ko directly 2 mat samjho.

React me:

setActiveTab(2);

ka matlab hai:

"React, meri activeTab state ki next value 2 kar do aur component ko dobara render karo."

Phir React dobara JSX evaluate karta hai:

activeTab === 1
activeTab === 2
activeTab === 3

Aur isi ke basis par classes change hoti hain.

Final mental model 🧠
Bas ye chain yaad rakho:

CLICK
  ↓
onClick
  ↓
isOpenSubmenu(index)
  ↓
setActiveTab(...)
  ↓
STATE CHANGE
  ↓
RE-RENDER
  ↓
activeTab === index
  ↓
className change
  ↓
CSS class apply
  ↓
SUBMENU OPEN / CLOSE

Aur multiple submenu ka pura game activeTab ke number ka hai.

Product click  → activeTab = 1
Category click → activeTab = 2
Orders click   → activeTab = 3

Jis number ka activeTab hai, sirf wahi submenu colapse hoga; baaki sab colapsed honge.
